The empty [Releases page](https://github.com/zyravo-store/zydevkit/releases) is intentional: a private packaging

checksums, release notes, and version metadata appear together only after the
complete release gate passes.

## What ZyDevKit does

- Inspect and transform common developer data formats.
- Use focused browser utilities from one developer toolbox.
- Run supported tools across Chrome, Edge, Firefox, and Safari.

## Distribution channels

- **Chrome, Edge, and Firefox:** official browser stores when available, or
  verified manual packages from GitHub Releases.
- **Safari:** Mac App Store after Apple validation.
- **macOS direct download:** Developer ID signed, notarized, and stapled DMG
  and PKG packages after the public release gate passes.
- **Windows and Linux:** browser-extension bundles with SHA-256 checksums;
  these are not native EXE, MSI, DEB, RPM, or AppImage applications.
